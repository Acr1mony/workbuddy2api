账号

选一个域生成登录链接，在浏览器里打开并完成授权，本页会自动把账号收进来。

从已登录的 WorkBuddy / CodeBuddy 客户端里读 refreshToken。它是一次性的： 网关拿到后会立刻换掉旧值，别在别处再用同一个。

只贴 accessToken 的账号过期后需要手动续期；有 refreshToken 才能自动保活。

              接在客户端自己的 system 提示词末尾（不覆盖、也不参与 sanitize）。适合放"习惯"类要求：
